## 📖 프로젝트 소개

Essage는 팀원 간 원활한 소통과 정보 공유를 목적으로 개발한 React 기반 웹 애플리케이션입니다.

팀별 게시글 작성 및 조회, 댓글, 사용자 프로필 관리 등의 기능을 통해 팀원 간 협업을 지원합니다.

---

## 🛠 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React 19, JavaScript, HTML5, CSS3 |
| Routing | React Router DOM |
| State Management | Zustand |
| UI | Bootstrap 5, React-Bootstrap |
| Build | Vite |
| Deployment | GitHub Pages |
| Collaboration | Git, GitHub |

---

## 👩‍💻 담당 역할

- 프로젝트 기획 및 화면 설계 참여
- 팀별 게시글 상세 페이지 UI 및 기능 구현
- 게시글 조회·댓글·수정·삭제 사용자 상호작용 구현
- React 기반 재사용 컴포넌트 개발
- 마이페이지 및 사용자 프로필 수정 화면 구현
- 작성 게시글·댓글 활동 요약 UI 구성

---

## ✨ 주요 기능

- 회원가입 및 팀 소속 참여
- 팀별 커뮤니티 게시글 작성 및 조회
- 게시글 상세 페이지 및 댓글 기능
- 사용자 프로필 및 마이페이지
- React Router 기반 페이지 이동
- Zustand를 활용한 전역 상태 관리
- 반응형 웹 UI

---

## 💭 프로젝트 회고

Essage 프로젝트를 통해 React의 컴포넌트 기반 UI 설계와 상태 관리에 대한 이해를 높일 수 있었습니다.

게시글 상세 페이지와 마이페이지를 구현하면서 컴포넌트 재사용과 사용자 상호작용을 경험했으며, 단순히 화면을 완성하는 것을 넘어 코드의 유지보수성과 재사용성을 고려하는 것이 중요하다는 점을 배웠습니다.
